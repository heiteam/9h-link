联系我们

有问题、建议或反馈？欢迎随时来信

📧 电子邮件

cp@9h.hk

这是我们唯一的官方联系渠道。我们会在 1-2 个工作日内 回复您的邮件。如果是周末或法定节假日，回复可能会稍有延迟，请耐心等待。

发邮件时，建议在标题中简要说明问题类型（如「功能反馈」「Bug 报告」「合作咨询」），方便我们快速分类处理。

💬 功能建议

如果你在使用过程中发现了不便之处，或者有新的功能想法，欢迎来信告诉我们。我们会认真考虑每一条反馈，持续改进产品。

短链接审核相关：如果你发现某个短链接指向恶意内容，或者你的短链接审核未通过需要申诉，请通过邮件联系我们，邮件标题请注明「审核申诉」。

常见的有效反馈包括：具体的操作步骤描述、期望的功能效果、以及你目前使用的替代方案。越具体的反馈，我们越容易理解和实现。

🐛 Bug 报告

如果遇到了功能异常，请尽量提供以下信息，帮助我们快速定位问题：

  • 使用的浏览器和版本（如 Chrome 120、Safari 17）
  • 操作系统（如 Windows 11、macOS Sonoma、iOS 17）
  • 问题的具体表现和复现步骤
  • 如有截图或错误提示，请一并附上

🤝 合作联系

如有商业合作意向（如 API 接入、品牌联名、渠道推广等），请通过邮箱联系我们，并在邮件中注明：

  • 公司或团队名称
  • 合作方向和预期目标
  • 联系方式（邮箱或电话）

我们会根据合作类型评估可行性，并在 3 个工作日内给予初步回复。

⚠️ 非联系渠道

请注意，以下方式不是我们的联系渠道：

  • 社交媒体私信（我们暂未开设官方社交账号）
  • 短信或电话（我们不提供电话支持）
  • 第三方平台留言

为保障你的信息安全，请仅通过官方邮箱 cp@9h.hk 与我们联系。
